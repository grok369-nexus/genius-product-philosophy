# GENIUS Product Philosophy

A reusable AI agent skill for discovering, designing, and building simple, meaningful software with extraordinary capabilities and effortless user experiences.

## Skill

- [Genius Product Builder](skills/genius-product-builder/SKILL.md)

The skill helps AI agents follow the GENIUS philosophy: make life better, more exciting, and more meaningful without stressing the user.

## Guiding standard

**Extraordinary technology. Effortless experiences. Meaningful lives.**

## Use

Provide the skill file to your AI coding agent as its product-thinking and design guidance. Pair it with the specific product brief, repository context, and technical requirements for each project.

The skill is a guide, not a substitute for project-specific requirements or testing.
